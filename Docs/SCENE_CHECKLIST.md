# Scene Wiring Checklist

Before testing a scene, confirm that the active panorama is visible, every
hotspot has an interactable UI target, and the fade image is assigned to the
scene navigator. The Main Menu also needs valid scene names on both buttons.

After changing a reference, enter Play mode once and test every destination in
both directions. A missing serialized reference is otherwise easy to miss in a
scene that opens on the correct initial panorama.
