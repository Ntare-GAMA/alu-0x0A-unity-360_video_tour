# Commit Formats

Use an imperative subject with a short scope when useful. This project uses
several readable forms:

- `feat(scope): add behavior`
- `fix(scope): correct behavior`
- `docs: explain workflow`
- `test: record verification`
- `refactor(scope): simplify code`
- `chore: update project maintenance`

Keep each commit focused on one behavior, document, or maintenance concern.
